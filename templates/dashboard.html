    Qué es DataLab

    DataLab es un laboratorio interactivo construido para el proyecto integrador del Módulo 12. Todas las estructuras de datos (arreglos dinámicos, listas enlazadas, pilas, colas, árboles BST/AVL/B, grafos, tablas hash y montículos) y todos los algoritmos (búsquedas, ordenamientos, programación dinámica y greedy) están implementados desde cero en el backend Python. El frontend solo visualiza los resultados reales que produce la API REST: nada está simulado. Cada laboratorio incluye controles, visualización paso a paso y el análisis Big O del algoritmo en ejecución.

    Cómo usarlo en una demostración: abra un laboratorio desde los accesos rápidos, ejecute las operaciones con el reproductor (ejecutar, pausar, paso a paso, velocidad) y apóyese en el panel de información técnica para explicar complejidad temporal y espacial con datos medidos, no estimados.
