Información técnica

Función hash propia: h = (h·31 + carácter) mod capacidad (polinomial, determinista, comparable a djb2). La calidad del hash decide cuántas colisiones habrá.

Encadenamiento (chaining): cada bucket guarda una lista de pares; las claves que colisionan conviven en la misma cadena y ninguna se pierde.

insert / search / remove: O(1) promedio · O(n) peor caso (todo colisiona en un bucket)
Factor de carga α = n/m: se redimensiona al duplicar la capacidad cuando α > 0.75
Rehash: O(n) pero amortizado: en promedio cada inserción cuesta O(1)
Espacio: O(n + m) — buckets + cadenas
